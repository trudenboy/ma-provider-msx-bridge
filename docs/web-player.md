# Browser Web Player

The browser web player and kiosk (`/web`, including Sendspin kiosk mode)
are no longer part of MSX Bridge.

Use the standalone [Web Kiosk](https://github.com/trudenboy/ma-provider-web-kiosk)
provider for always-on displays, karaoke, the visualizer, and
Sendspin-synchronized browser playback.

This provider now serves Media Station X on Smart TVs only. Point the
MSX app at `http://<SERVER_IP>:8099/msx/start.json`.
