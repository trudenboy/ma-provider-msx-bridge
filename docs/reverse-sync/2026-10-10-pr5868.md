# MSX Bridge upstream review backport

Source: [Music Assistant server PR #5868](https://github.com/music-assistant/server/pull/5868), head `515cdf8639b52415330eafdc2d53ea581dc3d890`.

The existing [provider PR #279](https://github.com/trudenboy/ma-provider-msx-bridge/pull/279) supplies the typed sorting API from upstream #5498. Its import conflict is resolved by retaining the split-provider imports and adding the sort enums. No duplicate sorting backport PR is created.

Four provider commits by Marcel van der Veldt are imported with their original author identity:

- `2b07eee704502c143cd7e6c68c795c7750d94443`: remove dead code and the unused Content-Length setting, including Node-only tests from the exported suite.
- `9777d759c2bc9840922e7a12f777a310cc846358`: report idle at native queue completion so core handles refill/end-of-queue.
- `ad2ce5c70c45c6669d3730a5f975cedf7fbc2592`: close the ffmpeg async generator on cancellation.
- `515cdf8639b52415330eafdc2d53ea581dc3d890`: use real Music Assistant queue objects in provider tests.

The upstream dev merge remains in MA. The configuration migration commit `e1f45b982437e5d36c07bf96e9e9943eca584b48`, its core tests and generated translations are not copied into the provider repository. The migration is maintainer-approved in upstream PR #5868 and must remain there: it removes retired MSX settings, maps shared delivery to independent and removes obsolete `spb_msx_` players, DSP configurations and cached protocol links.

Provider `VERSION` and manifest metadata are unchanged. The next changelog entry is 1.6.2; this backport does not publish a release or merge either PR.

Physical TV confirmation of final-track eject and Endless Mix continuation remains pending on this exact upstream revision. Earlier device reports do not prove those revised behaviors.

Validation completed against official MA dev `288c9e89d65345511aeb8004f59234c98dfe659b`, Python 3.14.3 and models 1.1.221: 343 provider tests and 18 standalone tests passed; upstream lint, mypy and configuration/label/manifest/test-layout checks passed. Provider `pre-commit run --all-files` also passed with a temporary `MYPYPATH` overlay exposing real MA types and the canonical `tests.providers.msx_bridge` namespace. No checker rules or implementation files were changed for that environment correction.
