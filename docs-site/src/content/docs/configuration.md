## Requirements

- MSX installed on Smart TV or device running the MSX player
- Music Assistant server accessible from the TV network
- IP address of the TV running MSX

## Adding the Provider to Music Assistant

1. Open **Music Assistant → Settings → Providers**
2. Click **Add Provider** and select **MSX Bridge**
3. Enter the **IP address** of your MSX device
4. Click **Save**

## Parameters

| Parameter | Description | Default |
|:----------|:------------|:--------|
| IP Address | IP of the MSX player device | — |
| Port | MSX player HTTP port | 8080 |
