## How to Contribute

1. Fork the repository
2. Create a branch `feat/description`
3. Make changes and add tests
4. Open a Pull Request to `feat/msx-bridge-player-provider`

## Code Style

The project uses [ruff](https://docs.astral.sh/ruff/) for linting and formatting:

```bash
uv run ruff check .
uv run ruff format .
```
